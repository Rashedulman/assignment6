1.What is the difference between var, let and const?  Answer: The difference between var, let and const are - var is function-scoped and can be redeclared and reassigned while let is block-scoped and can be reassigned but not redeclared whereas const is block-scoped and cannot be reassigned or redeclared
2. What is the difference between map(), forEach() and filter()?  Answer: The difference between map(), forEach() and filter() are forEach() executes a function for each array element and returns nothing on the other hand map() creates and returns a new array with modified elements whereas filter() creates and returns a new array containing elements that match a condition.
3. What are Arrow Functions in ES6?  Answer: Arrow functions are a shorter syntax for writing functions in ES6. They make code cleaner and do not have their own this.
4. How does Destructuring Assignment work in ES6?  Answer: Destructuring allows values from arrays or properties from objects to be extracted and assigned to variables easily.
5. Explain Template Literals in ES6. How are they different from string concatenation?  Answer: Template literals use backticks (``) and ${} to embed variables and expressions inside strings. They are more readable and support multi-line strings, unlike string concatenation with +.
